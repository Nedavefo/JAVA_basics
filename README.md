# Java Basics

Introductory Java exercises (coursework).

| File | What it covers |
|---|---|
| `Employee.java` / `EmployeeTest.java` | Class with constructor, getters/setters and validation (a non-positive salary is set to 0) |
| `Invoice.java` / `InvoiceTest.java` | Invoice with quantity and price validation and a computed invoice amount |
| `Week2.java` | Conditionals and `switch` statements |

## Run

```bash
javac *.java
java EmployeeTest
java InvoiceTest
```
